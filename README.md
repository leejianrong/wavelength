# wavelength

A Wavelength game played between one human and one LLM agent, or two LLM agents, built on [`agent-game-framework`](https://github.com/leejianrong/agent-game-framework). One player sees a hidden target on a spectrum between two opposites and gives a short clue; the other turns a dial to where they think it is.

**Status:** planning only, no game code yet. Start at [`docs/PLAN.md`](docs/PLAN.md); the build order is in [`docs/SLICES.md`](docs/SLICES.md), decisions in [`docs/adr/`](docs/adr), and open questions in [`docs/QUESTIONS.md`](docs/QUESTIONS.md).

This is an independent implementation with original content. "Wavelength" is a commercial game by Palm Court / CMYK; this project is not affiliated with or endorsed by them.
