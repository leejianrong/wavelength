# wavelength

Cooperative two-player Wavelength for a human and an LLM, or two LLMs, on [`agent-game-framework`](https://github.com/leejianrong/agent-game-framework). If this file, `docs/`, and the code disagree, trust the code and fix the doc in the same PR.

## What and why

Python 3.12, uv. `src/wavelength/engine.py` is the game; `cli.py` registers it into the framework's CLI. The plan and its reasoning are in `docs/PLAN.md`, the build order in `docs/SLICES.md`, decisions in `docs/adr/`. Read the ADR before changing what it covers.

Done: every slice, V0-V15 (framework changes, engine, matches, LLM seats + eval, chat, MCP seat, the Svelte web UI, AI seats and named personalities, voice and faces through a vikaki hub, thinking players, a live needle with the guesser's thoughts and the psychic's reaction, an AI guesser that works the needle in steps, and the human thinking aloud or speaking a clue by the browser's recogniser). Live-model quality (deepseek-v4.1-flash self-play, against 0.57 for random): 1.67 points/round without notes (60 rounds), 2.08 with them (53 rounds); the final eval (2026-10-25, 30 rounds each, `docs/final-eval.md`) gave 1.93 with notes and 1.83 with notes and needle steps, not distinguishable. It cost about 35 cents against 25 approved: reasoning tokens made the estimate low, so cap tokens as well as calls. Open: AGE-42, the cause of the earlier OpenRouter 403 (it did not recur). Named zones were tried and rejected (ADR-0007, superseded): the target is a number.

## Commands

`make` lists them. The ones you will use: `make all` (everything CI runs, Node 24 needed for the web UI), `make play-bot` (no key), `make web` (play in the browser against a bot), `make web-voice VIKAKI_DIR=...` (with voices and faces), `make play` (LLM, needs `.env`). Web flags and what they cost are in the README. Tests are `tests/unit` (no I/O), `tests/integration` (in-process `Match`), `tests/e2e` (the installed script, LLM mocked), plus the web UI's own `web/test` (dial maths) and `web/e2e` (Playwright, `make test-web`). Playwright's fixtures leave orphaned servers behind and the voice specs flake when the machine is busy: kill stray `wavelength web` and `_stub_hub.py` processes first and run `npx playwright test --workers=2`.

## Rules that are easy to break

- **The target must never reach the guesser.** Only `WavelengthEngine.observation_for` decides visibility. Anything new that prints or sends game data (an output, a prompt, an error message) needs a leak case in `tests/integration/test_match.py` or `tests/e2e/`. Use `observation_for(viewer)`, never `serialize`, for anything a player or LLM sees.
- **Do not add randomness to `apply_action`.** The whole round plan is drawn in `initial_state` from the seed. Bots must be deterministic given the observation.
- **The framework is pinned to a commit** in `pyproject.toml`, not a path. We rely on its registry dicts and on replacing `framework_cli.build_controller` and `framework_cli.Match` (`cli.py`), none of which is a public API: bump the pin deliberately and run `make all`.
- **LLM seats go through `GuardedSeat`** (`seats.py`). The framework retries an illegal move forever; the guard bounds it at 3 attempts and tells the model why. It also drops banter on clue turns, because the framework prints banter to the other player and the psychic knows the target. Do not bypass it for a new LLM path.
- **Chat context comes only from `chat_guard.chat_context`**, an allow-list. Never build it by copying an observation and removing fields. A seat that is the psychic must not reach the model in chat.
- **A browser gets only what one seat may see**, built in `WebSession._render` (`src/wavelength/web/`) from `observation_for`; the wire format and its five rules are in `docs/web-protocol.md`. In short: a spectator sees the guesser's view unless they peek, peek is refused when a human is seated, banter comes only from guess turns, and raw exception text never goes to a page (a framework error can hold a model's output). Anything new that goes to a browser needs a leak case in `tests/integration/test_web_session.py`, `tests/e2e/test_web.py` or `web/e2e/`. The page holds no game logic.
- **The voice tap is a speaker, not a reader** (`voice.py`): it takes a seat and public text or a round's points, never an observation. `WebSession` decides what is public (banter only from a guess turn, no chat refusal). It is never fatal: a failed hub means a text game. Anything new sent to the hub needs a case in `tests/integration/test_voice.py`, which scans a whole match's traffic against an allow-list. The hub token goes to drivers only, never to a page or an iframe URL; the page posts only to the hub's origin, never `*`.
- **Thinking notes stay in the seat** (`thinking.py`): a psychic's notes name the target, so they go back to the same model and nowhere else (not the other seat, chat, a page or the hub). The notes call goes through the same `Meter` and sits inside `GuardedSeat`. Anything that would show or send them needs ADR-0010 revisited (V13).
- **Needle drafts are public numbers, never actions** (`WebSession.draft`, ADR-0011): they reach the page only, never the engine or a seat. A psychic's notes leave the server once, in `reaction`, after the reveal; a guesser's `thinking` is the only other thought sent. A guesser's needle steps (`NeedleSeat`, ADR-0012) are public by construction: their prompts hold only the guesser's own allow-list, and a psychic never steps. Anything new that shows a seat's thinking needs ADR-0011 and ADR-0012 revisited.
- **Speech goes one way** (`WebSession.heard`, ADR-0013): a human guesser's words, in its own guess turn, are shown and (after the reveal) given to an AI psychic's reaction; a human psychic's are refused in every phase; a spoken clue stays in the browser; the hub is never told what a person said.
- **An agent seat is an AI seat** (ADR-0014): a `provider = "semula"` player is `OpenRouterBackend(base_url=<semula project>)` through the same `guard(metered(...))`. The address and project are operator config (`Semula`), never sent to a page; at most one agent per match, because two on one semula project would share a context and one would see the target; notes and needle steps are off for it.
- **AI matches in the browser are capped**: every AI seat is `guard(metered(...))` with one shared `Meter` per match. A new path that calls a model must go through it.
- **A personality is operator config** (`players.py`): it goes to the model as `system_prompt` and nowhere else; a page and the chat context never get its text. It cannot weaken a rule, so a new path that builds a seat still goes through `GuardedSeat`.
- **The model is `deepseek/deepseek-v4.1-flash`** on OpenRouter (the `Makefile` default). `deepseek/deepseek-v4-flash` (no `.1`) is blocked by the workspace guardrail and answers 404 "Model blocked by guardrail", before any spend. Use it for evals, defaults and examples.
- **CI never calls OpenRouter.** Mock it (`tests/e2e/_mock_openrouter.py`). `.env` is gitignored; never log the key.

## Workflow

Branch per slice off fresh `main`; PR only, after CI is green. A costly-to-reverse decision gets an ADR (Context / Decision / Alternatives / Consequences). Install the hooks once with `make install`. See `CONTRIBUTING.md`.
